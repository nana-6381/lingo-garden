# Reviewer quick start

1. Install Node.js 22.13+ and unzip the package.
2. From the exported folder, run npm install and npm run dev.
3. Open http://127.0.0.1:5173.

The ZIP includes app source, a dependency lockfile, license, observations, and evaluation fixtures. It excludes API keys, local learner data, node_modules, and the live Site's hosting identity.

## Course review

Only completed and current course nodes are enabled. Complete a lesson to unlock the next node. Tap dotted-underlined words for meanings. Correct answers turn green and bounce; wrong words are highlighted red. Korean text fields offer an on-screen keyboard.

After a lesson, choose the conversation handoff for the curated Bridge flow. Compare two shop replies and apply the location phrase in a new café exchange.

## Roleplay review

Select Roleplay in the main navigation. Choose a café, directions, or shop scenario, select A1/A2 and an explanation language, then start. Type or dictate a Korean reply. Translation, audio playback, hints, and goal progress are available. End the chat for an estimated scorecard and one-time XP award.

Live AI requires a funded API key configured securely in .env.local (local) or as ANTHROPIC_API_KEY in hosting secrets. Keys are intentionally excluded from the review ZIP. See ROLEPLAY-VERIFICATION.md for what has and has not been verified.
